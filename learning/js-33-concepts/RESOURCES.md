# 33 JavaScript Concepts Resources

## Knowledge

- [33 JavaScript Concepts](https://33jsconcepts.com/)
  主线学习材料。Use for: 33 个核心概念的结构化阅读、代码例子和延伸资料入口。

- [33 JavaScript Concepts: llms.txt](https://33jsconcepts.com/llms.txt)
  官方文档索引。Use for: 确认概念列表、查找每个主题的 markdown 页面。

- [Primitive Types](https://33jsconcepts.com/concepts/primitive-types)
  第一个学习主题。Use for: JS 原始类型、不可变性、`typeof` quirks、autoboxing、`null` vs `undefined`。

- [MDN: JavaScript data types and data structures](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Data_structures)
  高可信基础参考。Use for: 类型系统、primitive/object 区分、规范化术语校准。

- [You Don't Know JS Yet](https://github.com/getify/You-Dont-Know-JS)
  深入理解 JS 语言机制的免费书。Use for: scope、closures、objects、types、coercion 等难点补充。

## Wisdom (Communities)

- [TC39 Proposals](https://github.com/tc39/proposals)
  JavaScript 语言演进的一手入口。Use for: 判断语法特性和提案状态，避免只靠二手文章理解语言变化。

- [MDN GitHub Discussions](https://github.com/mdn/content/discussions)
  文档与 Web 平台知识讨论。Use for: 查证 API 文档和边界行为。

## Gaps

- 后续每个主题学习时，需要把高质量专题资源补充进来，尤其是 Event Loop、V8、Promises、Prototype、Memory Management。
- 如果某个主题需要面试官视角的真实题库，需要单独补充来自实际面试复盘或公开高质量题库的材料。
