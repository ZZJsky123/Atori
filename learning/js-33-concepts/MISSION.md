# Mission: 33 JavaScript Concepts

## Why
通过 33 个 JavaScript 核心概念，把已有 4 年前端经验沉淀成更稳定的语言运行时理解，并能以面试官视角提出高水平追问，区分候选人是会用 API 还是理解机制。

## Success looks like
- 能用自己的话解释 JS 类型、作用域、闭包、原型、异步、事件循环、内存和引擎优化的核心机制。
- 每个核心概念至少沉淀一个代码实验、一个真实工程关联、一个基础题和一个追问题。
- 形成可复用的个人面试题库，用于判断候选人的 JS 理解深度。
- 在 `learning/js-33-concepts/` 中持续沉淀学习主旨、计划、记录、资料和后续课程。

## Constraints
- 总学习周期为 6 周。
- 每天建议投入 60-90 分钟。
- 学习对象不是 JS 初学者，而是已有前端经验的开发者。
- 输出需要兼顾语言综合理解力、代码设计能力、工程化判断和面试官提问能力。

## Out of scope
- 不追求完整覆盖浏览器所有 Web API。
- 不把计划写成入门教程。
- 目前不把 `src/app/posts/js-33-concepts.md` 用作学习记录；博客 posts 区保持干净，等形成可发布文章后再输出。
